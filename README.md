# ប្រព័ន្ធគ្រប់គ្រងសៀវភៅសិក្សាគោល និងរបាយការណ៍បោះពុម្ភជាផ្លូវការ
### (Textbook Stock, Borrowing, Google Sheets Cloud Database & Official Reporting System)

ប្រព័ន្ធគ្រប់គ្រងសៀវភៅសិក្សាគោលនេះ ត្រូវបានសិក្សាស្រាវជ្រាវ និងអភិវឌ្ឍន៍ឡើងដោយផ្អែកលើគំរូនៃគេហទំព័រ [https://bookborrowsihamoni.vercel.app/](https://bookborrowsihamoni.vercel.app/) ដោយបានបន្ថែមសមត្ថភាពយ៉ាងពេញលេញក្នុងការប្រើប្រាស់ **Google Sheets ធ្វើជា Cloud Database** ដែលទាញយកទិន្នន័យស្វ័យប្រវត្តិតាំងពីពេលបើកដំណើរការដំបូង និងសមកាលកម្មទិន្នន័យដូចគ្នាលើគ្រប់ឧបករណ៍ (Multi-Device Auto-Sync) ព្រមទាំងភ្ជាប់ជាមួយ **មជ្ឈមណ្ឌលរៀបចំរបាយការណ៍កម្រិតខ្ពស់** និង **ប្រព័ន្ធ Activity Notifications** តាមដានរាល់សកម្មភាពក្នុងប្រព័ន្ធ។

## 🌟 លក្ខណៈពិសេសចម្បងៗ (Key Features)

### ១. ការផ្ទុកទិន្នន័យលើ Google Sheets (Cloud Real-Time Database) ☁️
- **ទាញយកទិន្នន័យស្វ័យប្រវត្តិ (Auto-Fetch on Startup)**៖ រាល់ពេលបើកកម្មវិធីលើ Browser ណាមួយ ប្រព័ន្ធនឹងទាញយកទិន្នន័យសៀវភៅ សិស្ស ប្រតិបត្តិការខ្ចី-សង និងការកំណត់ចុងក្រោយពី Google Sheets ដោយស្វ័យប្រវត្តិ។
- **រក្សាទុកគ្រប់ប្រតិបត្តិការ (Auto-Save on Every Action)**៖ រាល់ពេលមានការខ្ចី សង បន្ថែមសៀវភៅ កែសម្រួលស្តុក ឬកែប្រែទិន្នន័យសិស្ស ប្រព័ន្ធនឹងបញ្ជូនទៅរក្សាទុកលើ Google Sheets ភ្លាមៗ។
- **ទិន្នន័យដូចគ្នាលើគ្រប់ឧបករណ៍ (Multi-Device Synchronization)**៖ បណ្ណារក្សអាចប្រើប្រាស់កុំព្យូទ័រ Laptop, Tablet, ឬទូរស័ព្ទដៃច្រើនក្នុងពេលតែមួយ ដោយទិន្នន័យសមកាលកម្មស្វ័យប្រវត្តិ និងមានប៊ូតុង Refresh/Pull នៅលើ Top Bar។
- **ស្លាកសញ្ញា Cloud Status Pill**៖ បង្ហាញស្ថានភាពលើ Top Bar ភ្លាមៗ (ចំណុចពណ៌បៃតង = បានភ្ជាប់ Cloud, ចំណុចពណ៌ខៀវ = កំពុងសមកាលកម្ម, ពណ៌ប្រផេះ = ទិន្នន័យក្នុងម៉ាស៊ីន Offline)។
- **មានឯកសារកូដ Google Apps Script រួចជាស្រេច**៖ នៅក្នុងថត `google-apps-script/Code.gs` ដែលបានរៀបចំ Tabs ក្នុង Google Sheet យ៉ាងស្អាត (`Books`, `Students`, `Borrowings`, `Settings`, `ActivityLogs`)។

### ២. ប្រព័ន្ធ Notification និងតាមដានសកម្មភាព (Activity Notifications Center) 🔔
- **កណ្តឹងជូនដំណឹងលើ Top Bar**៖ មានលេខ Badge បង្ហាញចំនួនសកម្មភាពថ្មីៗដែលមិនទាន់អាន។
- **ផ្ទាំងទម្លាក់ Dropdown Notification**៖
  - បង្ហាញរាល់សកម្មភាពក្នុងប្រព័ន្ធដូចជា៖ កត់ត្រាការខ្ចី, ការសងសៀវភៅ, ការបន្ថែម/កាត់ស្តុក, ការបញ្ចូលសិស្ស, និងការសមកាលកម្ម Cloud។
  - កាលបរិច្ឆេទជាភាសាខ្មែរតាមពេលវេលាជាក់ស្តែង (ឧ. "មុននេះបន្តិច", "៥ នាទីមុន", "ម្សិលមិញ")។
  - អាចសម្អាត (Clear) ការជូនដំណឹងទាំងអស់បាន។
- **ការជូនដំណឹងលើកុំព្យូទ័រ (Desktop Push Notifications)**៖ អាចបើកដំណើរការដើម្បីឱ្យប្រព័ន្ធលោត Pop-up នៅជ្រុងអេក្រង់កុំព្យូទ័រ។
- **Floating Toast Notifications**៖ លោតផ្ទាំងតូចៗស្អាតៗនៅជ្រុងខាងលើបញ្ជាក់រាល់ពេលប្រតិបត្តិការជោគជ័យ។

### ៣. ឧបករណ៍រៀបចំរបាយការណ៍កម្រិតខ្ពស់ (Advanced Report Organizer) 📊
- **ជម្រើសកាលបរិច្ឆេទរហ័ស (Quick Date Presets)**៖ ចុចតែ ១ ឃ្លីកដើម្បីជ្រើសយក [ថ្ងៃនេះ], [សប្តាហ៍នេះ], [ខែនេះ], [ឆមាសទី ១], [ឆមាសទី ២], ឬ [ឆ្នាំសិក្សាទាំងមូល]។
- **ជ្រើសរើសជួរឈរតាមបំណង (Custom Column Selector)**៖ អាចគូសធីកជ្រើសរើសជួរឈរណាខ្លះដែលចង់បង្ហាញ ឬលាក់នៅក្នុងតារាងបោះពុម្ភ (លេខរៀង, ឈ្មោះ, ថ្នាក់, សៀវភៅ, លេខទូរស័ព្ទ, ថ្ងៃខ្ចី, ថ្ងៃត្រូវសង, ស្ថានភាព)។
- **កែប្រែចំណងជើងរបាយការណ៍**៖ អាចវាយបញ្ចូលចំណងជើងរបាយការណ៍ថ្មីដោយផ្ទាល់តាមតម្រូវការជាក់ស្តែង។
- **បិទ/បើកប្លុកហត្ថលេខា**៖ អាចជ្រើសរើសបង្ហាញ ឬលាក់ប្លុកហត្ថលេខានាយកសាលា និងបណ្ណារក្ស។
- **មុខងារចម្លងតារាង (Copy to Clipboard)**៖ ចុចតែ ១ ឃ្លីក អាចយកតារាងទៅបិទភ្ជាប់ (Paste) ក្នុង Microsoft Word ឬ Microsoft Excel បានភ្លាមៗដោយមិនបាច់ទាញយក File។
- **របាយការណ៍ ៤ ប្រភេទផ្លូវការ**៖
  1. បញ្ជីឈ្មោះសិស្សខ្ចីសៀវភៅសិក្សាគោល
  2. របាយការណ៍ស្ថានភាពស្តុកសៀវភៅសិក្សាគោល
  3. បញ្ជីសិស្សយឺតយ៉ាវមិនទាន់ប្រគល់សៀវភៅសង (Overdue)
  4. តារាងស្ថិតិសង្ខេបប្រចាំឆមាស/ឆ្នាំសិក្សា (ជូននាយកសាលា និងការិយាល័យអប់រំ)

### ៤. ផ្ទាំងគ្រប់គ្រងទូទៅ (Dashboard)
- កាតស្ថិតិ ៥ សំខាន់ៗ (ចំណងជើងសៀវភៅ, ស្តុកសរុប, កំពុងខ្ចី, សល់លើធ្នើរ, និងហួសកាលកំណត់)។
- របារស្ថិតិនៃអត្រាខ្ចីតាមកម្រិតថ្នាក់ (៧ ដល់ ១២)។
- តារាងសកម្មភាពខ្ចី-សងថ្មីៗ និងប្រអប់ជូនដំណឹងសៀវភៅជិតអស់ពីស្តុក។

### ៥. ការគ្រប់គ្រងស្តុកសៀវភៅ និងសិស្ស
- បន្ថែម, កែប្រែ, លុប, និងកែសម្រួលស្តុកសៀវភៅសិក្សាគោល (+ / -)។
- បញ្ជីសិស្ស, មើលប្រវត្តិខ្ចី-សងផ្ទាល់ខ្លួនរបស់សិស្សម្នាក់ៗ។
- នាំចេញ / នាំចូល Excel (CSV) គាំទ្រ UTF-8 BOM សម្រាប់ភាសាខ្មែរ។

### ៦. បង្កាន់ដៃខ្ចី-សង (Print Voucher)
- បោះពុម្ភបង្កាន់ដៃមានក្បាលលិខិតជាតិ "ព្រះរាជាណាចក្រកម្ពុជា ជាតិ សាសនា ព្រះមហាក្សត្រ" ព័ត៌មានសាលា សិស្ស បញ្ជីសៀវភៅ និងកន្លែងចុះហត្ថលេខា/ស្នាមមេដៃ។

### ៧. ការរចនា និងបទពិសោធន៍ប្រើប្រាស់លើទូរស័ព្ទដៃ (Mobile-Friendly & Responsive UI) 📱
- **Mobile Bottom Navigation Bar**៖ មានរបាររុករកនៅផ្នែកខាងក្រោមអេក្រង់ទូរស័ព្ទ ងាយស្រួលចុចប្តូរទំព័រដោយមេដៃ (Dashboard, សៀវភៅ, ខ្ចី-សង, សិស្ស, របាយការណ៍, ច្រើនទៀត) ព្រមទាំងមានលេខ Badge ជូនដំណឹងសៀវភៅយឺតយ៉ាវទាន់ពេល។
- **Sidebar Drawer & Backdrop**៖ មឺនុយចំហៀងរំកិលចេញមកយ៉ាងរលូន (Slide-in) ជាមួយផ្ទៃខាងក្រោយងងឹតស្រាល (Blur Backdrop) និងប៊ូតុងបិទ (X)។
- **ផ្ទាំងគ្រប់គ្រងរៀបរយលើអេក្រង់តូច (2x2 Grid Stats)**៖ កាតស្ថិតិរៀបចំជា ២x២ យ៉ាងតូចល្មមលើអេក្រង់ទូរស័ព្ទ មិនបាច់អូសចុះក្រោមវែងអន្លាយ។
- **តារាងរំកិលផ្តេកជាមួយសញ្ញាណែនាំ (Touch-Friendly Table Scroll)**៖ មានស្លាកប្រាប់ "អូសផ្តេកដើម្បីមើលទិន្នន័យពេញលេញ" និងប៊ូតុងសកម្មភាពធំល្មមសម្រាប់ម្រាមដៃចុច។
- **របាយការណ៍បង្រួមតាមអេក្រង់ (Fit to Mobile View)**៖ ផ្ទាំង Preview របាយការណ៍ A4 អាចចុចប៊ូតុង [បង្រួមតាមអេក្រង់] ដើម្បីមើលទម្រង់ទាំងមូលដោយមិនបាច់រំកិលឆ្វេងស្តាំ ឬចុច [ទំហំពិត A4] ដើម្បីមើលអក្សរធំច្បាស់។
- **ប្រអប់ Modal Bottom-Sheet**៖ ផ្ទាំងបន្ថែមសៀវភៅ សិស្ស និងកត់ត្រាការខ្ចី បង្ហាញជាទម្រង់ Bottom-sheet ស្រួលវាយអក្សរ និងមានប៊ូតុង Save ជាប់នៅខាងក្រោមងាយស្រួលចុច។

## ☁️ របៀបតម្លើង Google Sheets ធ្វើជា Cloud Database

1. បើកកម្មវិធីរុករក រួចចូលទៅកាន់ [https://sheets.new](https://sheets.new) ដើម្បីបង្កើត Google Sheet ថ្មីមួយ។

4. បើកឯកសារ `google-apps-script/Code.gs` ក្នុងគម្រោងនេះ ចម្លងកូដទាំងអស់ទៅបិទភ្ជាប់ (Paste) ជំនួសកូដចាស់ក្នុង Apps Script។
5. ចុច Save (រូបថាស)
6. ចុចប៊ូតុង **Deploy (ដាក់ឱ្យប្រើប្រាស់)** &rarr; **New deployment**
7. ចុចលើរូបស្ពឺ Select type &rarr; ជ្រើសរើស **Web app**
8. កំណត់ដូចខាងក្រោម៖
   - **Description**: `BookStock Cloud API`
   - **Execute as**: `Me`
   - **Who has access**: `Anyone` *(សំខាន់ណាស់ ដើម្បីឱ្យកម្មវិធីអាចទាញយក និងរក្សាទុកទិន្នន័យបាន)*
9. ចុច **Deploy** &rarr; ចុច **Authorize access** &rarr; ជ្រើសរើសគណនី Gmail របស់អ្នក &rarr; ចុច **Advanced** &rarr; ចុច **Go to ... (unsafe)** &rarr; ចុច **Allow**
10. ចម្លង **Web app URL** (ដែលបញ្ចប់ដោយ `/exec`) យកមកបិទភ្ជាប់ក្នុងផ្ទាំង **"ការកំណត់ & Cloud Sync"** ក្នុងប្រព័ន្ធ BookStock រួចចុច "រក្សាទុក URL ការកំណត់"។
11. រួចរាល់! ប្រព័ន្ធនឹងទាញយកទិន្នន័យពី Cloud ដោយស្វ័យប្រវត្តិតាំងពីពេលបើកដំណើរការដំបូង និងរក្សាទុកគ្រប់ប្រតិបត្តិការ។
