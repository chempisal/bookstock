ការភ្ជាប់ Google Sheets ធ្វើជា Cloud Database

ជំហានងាយៗក្នុងការតម្លើង Google Apps Script៖

  1. បង្កើត Google Sheet ថ្មីមួយលើ Google Drive (វាយចូល sheets.new)
  2. ដាក់ឈ្មោះ Google Sheet ឧទាហរណ៍៖ BookStock_Database
  3. ចុចលើមឺនុយ Extensions (ផ្នែកបន្ថែម) → Apps Script
  4. លុបកូដចាស់ចោលទាំងអស់ រួចចម្លងកូដខាងក្រោមយកទៅបិទភ្ជាប់ (Paste)
  5. ចុច Deploy (ដាក់ឱ្យប្រើប្រាស់) → New deployment
  6. ជ្រើសរើសប្រភេទ Web app រួចកំណត់ Who has access: Anyone (សំខាន់ណាស់!)
  7. ចុច Deploy → ផ្តល់សិទ្ធិ (Authorize access) → ចម្លង Web app URL មកដាក់ក្នុងប្រព័ន្ធ BookStock
